Read and follow `.claude/12sp/rules.md`. This command never edits project files.

Change and data: $ARGUMENTS

## Stages
1. **Preflight** — read `CLAUDE.md`.
2. **Gather inputs** — the original requirement (from an archived or current `.12sp/plan.md` for this change, if one exists; otherwise ask the user), plus usage data, metrics, logs, or support feedback. Ask the user for anything you can't access directly.
3. **post-launch-reviewer** — pass everything gathered.
4. **Write `.12sp/post-launch.md`** with its output.

Wrap up per the rules. If the recommendation includes lessons for future work (e.g. a quirk worth knowing), suggest a line to add to `CLAUDE.md` — but don't edit it yourself.
